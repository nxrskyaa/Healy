About

built by
nxrskyaa

Healy is a place to pass through, not a game to finish — a valley of grass, a pond, a railway line, and weather. Everything you can see or hear is generated by code at load time: there is not a single image, model, or audio file behind it.

github.com/nxrskyaa x.com/nxrskyaa
Built with Three.js. The grass and light owe a debt to a procedural landscape by Lentils80.
